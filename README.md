# MoVo (모보) — 폴더블 영상 상·하 정렬과 자막 색상

MoVo는 **재생 중 영상의 상·중·하 정렬을 선택**하고, **자막 색상을 둥근 스와치와 팔레트에서 고를 수 있는** Android 로컬 영상 플레이어입니다.
펼친 화면에서 자신의 시선과 사용 자세에 맞춰 영상을 배치하고, 자막 모양을 조정할 수 있습니다.

## 폴더블 화면에 맞춘 영상 상·하 정렬

폴더블의 넓은 내부 화면에서 가로 영상을 보면 위아래에 여백이 생길 수 있습니다.
영상을 항상 한가운데에 두는 대신, 펼쳐서 손에 들거나 기기를 놓고 보는 상황에 맞춰 시청 위치를 고르세요.

재생 중 자막·영상 설정에서 **영상 화면 세로 정렬**을 선택할 수 있습니다.

- **상단 (Top)**: 여백이 있는 영상을 화면 위쪽에 배치합니다.
- **중앙 (Middle)**: 영상을 화면 가운데에 배치합니다.
- **하단 (Bottom)**: 영상을 화면 아래쪽에 배치합니다.

선택한 정렬은 저장되어 다음 재생에도 적용됩니다.
화면 비율·채우기 설정과 별개로 위치를 선택할 수 있지만, 영상이 화면을 가득 채워 세로 여백이 없으면 위치 차이가 드러나지 않을 수 있습니다.

사용자가 직접 고르는 설정이며, 접힘 각도나 힌지를 감지해 자동으로 정렬하는 기능은 아닙니다.
영상을 항상 화면의 위쪽 또는 아래쪽 절반에만 표시하는 기능도 아닙니다.

## MPV 설정을 직접 입력 (mpv.conf)

설정의 **고급 MPV 엔진 설정**에서 편집기를 열고, libmpv에 전달할 옵션을 `key=value` 형식으로 한 줄씩 입력할 수 있습니다.
하드웨어 디코딩이나 재생 프로필 등을 직접 조정하고 싶은 사용자를 위한 기능입니다.
편집기에서 안내하는 입력 예시는 다음과 같습니다.

```ini
hwdec=auto
profile=fast
```

저장한 옵션은 재생 시 libmpv에 전달되며, **초기화**로 사용자 설정을 비울 수 있습니다.
이는 `mpv.conf` 스타일의 **설정 옵션 편집기**이지, `seek`·`loadfile` 같은 임의 명령을 실행하는 터미널이나 명령 콘솔이 아닙니다.
파일 기록·출력 장치 선택·스크립트·외부 설정 및 경로·네트워크·앱 관리 옵션에는 제한이 있습니다. `vf`·`af`는 알려진 단순 필터의 체인만 허용하며, 임의의 lavfi 그래프나 파일을 읽는 옵션은 허용하지 않습니다. 외부 설정·스크립트·미디어 파일의 자동 로딩은 끄고, 같은 폴더의 외부 자막 등은 앱이 명시적으로 전달합니다. 영상이나 플레이리스트 내부의 외부 파일 참조도 자동으로 따라가지 않으므로, 자체 영상 데이터를 담은 로컬 영상과 달리 다른 파일을 연결하거나 참조만 하는 미디어는 재생되지 않을 수 있습니다.
제한된 줄은 저장 전에 안내되며, 해당 줄을 직접 삭제한 뒤 저장해야 합니다. 모든 MPV 설정을 임의로 사용할 수 있는 것은 아니며, 허용된 옵션의 실제 지원 여부와 효과도 libmpv와 기기 환경에 따라 달라집니다.

## 기본 라이브러리·재생 기능

- **폴더 라이브러리**: 시스템 폴더 선택기로 영상 폴더를 등록하고 하위 폴더 탐색, 검색, 이름순 정렬을 지원합니다.
- **영상 정보**: 영상 목록과 이어보기에서 기존 제목·진행 상태·날짜·크기·경로와 함께 해상도, 자막 유무, 전체 길이를 간결하게 표시합니다. 내장 자막과 같은 폴더의 이름이 맞는 외부 자막을 확인하며, 표시할 항목의 정보를 필요할 때 읽어 저장합니다. 확인되지 않은 정보는 알 수 없음으로 표시합니다. 일시적인 정보 읽기 실패는 명시적인 새로고침이나 재시도로 다시 확인할 수 있습니다.
- **이어보기·미시청**: 재생 위치와 시청 완료 상태를 저장하고 이어보기 목록을 제공합니다. **미시청**은 직접 지정한 시청 완료·미시청 상태와 시청 완료 기준을 반영하며, 일부 재생했지만 아직 시청 완료가 아닌 영상도 포함합니다.
- **재생 제어**: 화면 중앙의 재생·일시정지 버튼 양옆에서 이전·다음 **파일**로 이동하며, 10초 탐색·배속·화면 비율 조절·터치 제스처를 지원합니다. 손가락을 움직이지 않고 길게 누르면 임시 배속이 적용되고, 손을 떼거나 제스처가 취소되면 이전 배속으로 돌아갑니다. 재생 위치 슬라이더는 영상 자체의 현재·전체 시간을 접근성 정보로 제공합니다. 오디오 포커스를 얻지 못하면 일시정지 상태를 유지하며, 직접 일시정지한 뒤에는 포커스가 돌아와도 자동으로 재개하지 않습니다.
- **남은 시간**: 재생 화면 아래의 음수 시간은 현재 배속과 길게 누르기의 임시 배속을 반영한 실제 남은 재생 시간 추정치입니다. 일시정지 중 배속을 바꾸어도 갱신되며, 저장하는 재생 위치와 전체 길이는 영상 자체의 시간 기준을 유지합니다.
- **자막·오디오**: 내장·외부 자막, 오디오 트랙 선택과 싱크 조절을 지원합니다. 자막 색상은 둥근 스와치와 팔레트에서 선택할 수 있습니다.
- **넓은 화면 배치**: 라이브러리는 화면 폭이 600dp 이상이면 왼쪽 탐색 영역과 오른쪽 콘텐츠 영역으로 나뉩니다.

## 지원 환경·기술 구성

Android 8.0 이상을 지원하며, Kotlin · Jetpack Compose / Material 3 · Room · libmpv로 구성됩니다. 로컬 파일 접근에는 Android Storage Access Framework(SAF)를 사용합니다.
