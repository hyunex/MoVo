# MoVo (모보) — 폴더블 디바이스를 위한 영상 상단 정렬

MoVo는 **폴더블 디바이스를 위한 영상 상단 정렬**을 핵심으로 만든 Android 로컬 영상 플레이어입니다.
영상이 늘 화면 한가운데에 있어야 하는 대신, 펼친 화면과 기기를 놓고 보는 상황에 맞춰 시청 위치를 직접 선택할 수 있도록 만들었습니다.

## 왜 상단 정렬인가요?

폴더블의 넓은 내부 화면에서 가로 영상을 보면 위아래에 여백이 생길 수 있습니다.
이때 영상을 중앙에 두는 배치가 모든 시청 자세에 가장 편한 것은 아닙니다.
MoVo는 영상의 크기나 비율뿐 아니라 **화면에서 영상이 놓이는 세로 위치**도 고를 수 있게 합니다.

상단 정렬은 여백이 있는 영상을 화면 위쪽에 배치하고 싶을 때 사용하는 선택입니다.
펼쳐서 손에 들거나 기기를 놓고 볼 때, 자신의 시선과 사용 방식에 맞는 위치를 찾아보세요.

## 영상 위치를 직접 선택

설정에서 영상의 세로 정렬을 선택할 수 있습니다.

- **상단**: 영상을 화면 위쪽에 배치합니다. MoVo가 가장 중요하게 생각하는 시청 방식입니다.
- **중앙**: 영상을 화면 가운데에 배치합니다.
- **하단**: 영상을 화면 아래쪽에 배치합니다.

선택한 정렬은 저장되며, 다음 재생에서도 적용됩니다.
세로 정렬은 화면 비율·채우기 설정과 별개의 선택입니다.
다만 영상이 화면을 가득 채워 세로 여백이 없으면 정렬에 따른 위치 차이가 드러나지 않을 수 있습니다.

이 기능은 사용자가 직접 고르는 설정입니다.
접힘 각도나 힌지를 감지해 자동으로 정렬하거나, 영상을 항상 화면의 위쪽 절반에만 표시하는 기능은 아닙니다.

## 기본 라이브러리·재생 기능

- **폴더 라이브러리**: 시스템 폴더 선택기로 영상 폴더를 등록하고 하위 폴더 탐색, 검색, 이름순 정렬을 지원합니다.
- **이어보기**: 재생 위치와 시청 완료 상태를 저장하고 이어보기 목록을 제공합니다.
- **재생 제어**: 재생·일시정지, 위치 탐색, 배속, 화면 비율 조절과 터치 제스처를 지원합니다.
- **자막·오디오**: 내장·외부 자막, 오디오 트랙 선택과 싱크 조절을 지원합니다.
- **넓은 화면 배치**: 라이브러리는 화면 폭이 600dp 이상이면 왼쪽 탐색 영역과 오른쪽 콘텐츠 영역으로 나뉩니다.

## 지원 환경·기술 구성

Android 8.0 이상을 지원하며, Kotlin · Jetpack Compose / Material 3 · Room · libmpv로 구성됩니다. 로컬 파일 접근에는 Android Storage Access Framework(SAF)를 사용합니다.
