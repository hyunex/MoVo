# MoVo (모보)

MoVo는 **MPV 기반 Android 로컬 영상 라이브러리 플레이어**입니다.
폴더에 저장된 영상을 탐색하고, 시청 기록을 관리하며, 마지막으로 보던 위치부터 이어서 재생할 수 있습니다.

## 주요 기능

- **폴더 탐색**: 시스템 폴더 선택기로 영상 폴더를 등록하고 하위 폴더 탐색, 검색, 이름순 정렬을 지원합니다.
- **시청 기록**: 재생 위치와 시청 완료 상태를 저장하고 이어보기 목록을 제공합니다.
- **묶음 관리**: 여러 영상의 묶음 재생, 시청 상태 변경, 기록 초기화, 확인 후 파일 삭제를 지원합니다.
- **재생 제어**: 중앙 재생·일시정지 버튼, 재생 위치 탐색, 배속, 화면 비율 및 영상 정렬을 조절할 수 있습니다.
- **자막·오디오**: 내장·외부 자막, 오디오 트랙 선택과 싱크 조절을 지원합니다.
- **터치 제스처**: 밝기·음량·재생 위치 조절, 더블탭 탐색, 핀치 확대, 길게 눌러 2배속 재생을 지원합니다.
- **화면 대응**: 휴대폰·태블릿·폴더블에 맞춘 화면 배치와 화면 잠금·회전 설정을 제공합니다.
- **사용자 설정**: 재생 속도 프리셋, 제스처 및 고급 MPV 옵션을 설정할 수 있습니다.

## 기술 구성

Kotlin · Jetpack Compose / Material 3 · Room · libmpv

파일 접근에는 Android Storage Access Framework(SAF)를 사용합니다. Android 8.0 이상을 지원합니다.
